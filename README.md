# Pessoa POO

Projeto de estudo em C# com Windows Forms para praticar conceitos de Programacao Orientada a Objetos.

## Objetivo do projeto

Praticar a criacao de classes, propriedades, heranca, encapsulamento simples e manipulacao de listas usando uma interface Windows Forms.

## Tecnologias utilizadas

- C#
- .NET Framework
- Windows Forms
- Visual Studio

## Funcionalidades

- Cadastro de usuarios em memoria
- Exibicao de usuarios em uma lista
- Remocao de usuarios cadastrados
- Visualizacao de dados do usuario selecionado
- Calculo de idade com base na data de nascimento
- Uso de heranca entre as classes `Pessoa` e `Usuario`

## Estrutura do projeto

```text
Pessoa-POO/
`-- Pessoa-POO/
    |-- Pessoa.cs
    |-- Usuario.cs
    |-- UsuarioExecucao.cs
    |-- Form1.cs
    |-- Program.cs
    |-- Pessoa-POO.csproj
    `-- Pessoa-POO.sln
```

## Como executar

1. Clone o repositorio:

```bash
git clone https://github.com/murilotpiai/Pessoa-POO.git
```

2. Abra a solucao `Pessoa-POO/Pessoa-POO.sln` no Visual Studio.
3. Compile e execute o projeto.

## Aprendizados

- Criacao de classes e objetos em C#
- Propriedades com `get` e `set`
- Heranca entre classes
- Manipulacao de listas em memoria
- Eventos de botoes no Windows Forms
- Organizacao inicial de projeto no Visual Studio
